## Features

### Core Functionality
- Daily Water Tracking
- Multiple Beverage Types
- Smart Goal Calculation
- Real-Time Progress Tracking
- Intelligent Reminders

### Analytics & History
- Comprehensive statistics with daily totals, averages, and intake insights
- Weekly bar charts, monthly heatmaps, and yearly activity calendars
- Streak tracking and goal completion monitoring
- Historical navigation across weeks, months, and years
- Success rate and hydration progress analytics

### Health Connect Integration
- Read and write hydration data using Android Health Connect
- Import data from Samsung Health, Google Fit, Fitbit, Garmin, Strava, and more
- Detect and manage entries from external sources

### Home Screen Widgets
Available widgets:
- HydroProgress Widget (4x1)
- HydroCompact Widget (2x1)
- HydroLarge Widget (4x2)

Features:
- Dynamic Theming
- Real-Time Updates

### Smart Notifications
- Context-aware reminders
- Adaptive reminder scheduling
- Goal-based reminder logic
- Boot persistence support

### Personalization & Themes
- Material 3 Expressive Design
- Dynamic Colors
- Dark Mode Support
- Extra customization options 😏

### Scientific Foundation
- Beverage Hydration Index (BHI) based hydration calculations
- EFSA and IOM hydration guideline support
- Activity-based intake adjustments
- Beverage-specific hydration multipliers

More details and research sources can be found inside the app settings or in [sources.md](app/src/main/assets/sources.md).
